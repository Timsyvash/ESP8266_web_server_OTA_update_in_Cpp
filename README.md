# ESP8266 Web Server & OTA Update Hub (C++/PlatformIO)

[ESP8266] [PlatformIO] [ElegantOTA] [C++]

Цей проєкт є надійним шаблоном для створення Wi-Fi пристроїв на базі мікроконтролера **Wemos D1 mini (ESP8266)**. Проєкт побудований на основі неблокуючої архітектури (з використанням `millis()`) та підтримує оновлення прошивки «повітрям» (OTA) безпосередньо через зручний веб-інтерфейс у браузері.

---

## 🚀 Основні можливості

* **Неблокуючий цикл (`non-blocking loop`)**: Система не використовує довгі затримки (`delay`), що дозволяє одночасно підтримувати стабільне з'єднання, обслуговувати вебсторінки та виконувати фонові задачі.
* **Підключення до Wi-Fi (`ESP8266WiFiMulti`)**: Автоматичне підключення до налаштованої мережі.
* **Вебсервер (`ESP8266WebServer`)**: Базова панель керування пристроєм на стандартному 80-му порті.
* **Браузерне OTA-оновлення (`ElegantOTA`)**: Завантаження нових бінарних файлів прошивки (`.bin`) через звичайний веббраузер без дротів.

---

## 🛠 Використані технології та бібліотеки

* **Апаратна платформа**: Wemos D1 mini (ESP8266, 4MB Flash).
* **Фреймворк**: Arduino (через PlatformIO у VS Code).
* **Основні бібліотеки**:
  * `ESP8266WiFi` / `ESP8266WiFiMulti` — керування бездротовою мережею.
  * `ESP8266WebServer` — синхронний HTTP-сервер.
  * `ElegantOTA` — сучасний і зручний інтерфейс для оновлення прошивки.
